BSP Camera OV5647 说明文档

本文档说明 OV5647 MIPI-CSI 摄像头 BSP 封装接口。该模块使用 esp_cam_sensor 检测和配置 OV5647，使用 esp_driver_cam 接收 MIPI-CSI 数据，并通过 esp_driver_isp 将 RAW8 转换为 RGB565 帧缓冲区。

模块输出固定为 RGB565，适合直接提交给同为 RGB565 的 LCD 显示链路，也可作为后续图像处理输入。

1. 模块概览

条目说明
摄像头型号OV5647
输入接口MIPI-CSI 2 lane
传感器输出RAW8
BSP 输出RGB565，2 字节/像素
默认格式MIPI_2lane_24Minput_RAW8_800x640_50fps
默认分辨率800 x 640
缓冲模型双帧缓冲，free queue + ready queue

2. 模块组成

文件职责
bsp_camera_ov5647.h声明摄像头参数、帧结构体和对外 API。
bsp_camera_ov5647.c实现 OV5647 检测、SCCB 初始化、CSI 控制器、ISP、帧缓冲队列和帧获取接口。
bsp_camera_ov5647说明文档.html本说明文档。

3.3 帧结构体

typedef struct {
    void *buffer;
    size_t len;
    uint32_t width;
    uint32_t height;
} bsp_camera_frame_t;

buffer 指向 RGB565 帧数据，len 是有效数据长度，width 和 height 描述当前帧尺寸。

4. 工作流程

  1. 调用 bsp_camera_ov5647_init()。
  2. 分配两个 800x640 RGB565 PSRAM 帧缓冲区。
  3. 创建 SCCB I2C bus，并通过 esp_cam_sensor 自动检测 OV5647。
  4. 查找并设置 MIPI_2lane_24Minput_RAW8_800x640_50fps 格式。
  5. 打开 OV5647 stream。
  6. 创建 MIPI-CSI controller，注册取空闲缓冲和传输完成回调。
  7. 创建并启用 ISP，完成 RAW8 到 RGB565 的转换。
  8. 应用循环调用 bsp_camera_ov5647_get_frame() 获取 RGB565 帧。
  9. 显示或处理完成后调用 bsp_camera_ov5647_return_frame() 归还缓冲区。

5. 函数说明

bsp_camera_ov5647_init()

初始化 OV5647、SCCB、MIPI-CSI、ISP 和内部帧缓冲队列。函数重复调用时，如果摄像头已经初始化，会直接返回 ESP_OK。

ESP_ERROR_CHECK(bsp_camera_ov5647_init());

bsp_camera_ov5647_deinit()

停止 CSI，关闭 ISP，关闭传感器 stream，并释放 SCCB、I2C、帧缓冲和队列资源。

ESP_ERROR_CHECK(bsp_camera_ov5647_deinit());

bsp_camera_ov5647_get_frame(bsp_camera_frame_t *frame, TickType_t timeout_ticks)

等待 ready queue 中的一帧 RGB565 图像。获取成功后，调用者拥有该帧缓冲的临时使用权。

bsp_camera_frame_t frame = {0};
esp_err_t ret = bsp_camera_ov5647_get_frame(&frame, pdMS_TO_TICKS(1000));
if (ret == ESP_OK) {
    // frame.buffer 是 RGB565 图像
}

bsp_camera_ov5647_return_frame(void *buffer)

归还由 bsp_camera_ov5647_get_frame() 返回的帧缓冲区。没有归还缓冲区会导致可复用帧缓冲减少，最终可能采集停滞。

ESP_ERROR_CHECK(bsp_camera_ov5647_return_frame(frame.buffer));

6. 使用示例

6.1 初始化并获取一帧

#include "bsp_camera_ov5647.h"

void app_main(void)
{
    ESP_ERROR_CHECK(bsp_camera_ov5647_init());

    bsp_camera_frame_t frame = {0};
    ESP_ERROR_CHECK(bsp_camera_ov5647_get_frame(&frame, portMAX_DELAY));

    // 使用 frame.buffer / frame.len / frame.width / frame.height

    ESP_ERROR_CHECK(bsp_camera_ov5647_return_frame(frame.buffer));
}

6.2 直接显示到 RGB565 LCD

#include "bsp_camera_ov5647.h"
#include "bsp_lcd_jd9365_10_1.h"

void app_main(void)
{
    ESP_ERROR_CHECK(bsp_lcd_init());
    ESP_ERROR_CHECK(bsp_camera_ov5647_init());

    while (1) {
        bsp_camera_frame_t frame = {0};
        if (bsp_camera_ov5647_get_frame(&frame, portMAX_DELAY) == ESP_OK) {
            ESP_ERROR_CHECK(bsp_lcd_draw_bitmap(0, 320,
                                                frame.width,
                                                320 + frame.height,
                                                frame.buffer));
            ESP_ERROR_CHECK(bsp_lcd_wait_flush_done(portMAX_DELAY));
            ESP_ERROR_CHECK(bsp_camera_ov5647_return_frame(frame.buffer));
        }
    }
}

7. 注意事项

  • 需要启用 CONFIG_CAMERA_OV5647 和 CONFIG_CAMERA_OV5647_MIPI_RAW8_800X640_50FPS。
  • 帧缓冲区位于 PSRAM，并按 64 字节对齐，适合 DMA/CSI 使用。
  • 调用 bsp_camera_ov5647_get_frame() 后必须调用 bsp_camera_ov5647_return_frame()。
  • 该模块默认输出 RGB565；如果显示链路也是 RGB565，可以避免 CPU 色彩转换。
  • SCCB 默认使用 GPIO7/GPIO8。若同一硬件还使用这些引脚作为触摸或其它 I2C 设备，需要统一 I2C 资源管理。
  • 当前封装固定为 800x640。若要支持其它 OV5647 格式，需要同步修改 Kconfig、格式名称、分辨率宏和帧缓冲大小。
