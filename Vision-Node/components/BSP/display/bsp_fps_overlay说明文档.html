BSP FPS Overlay 说明文档

本文档说明 RGB565 FPS 叠加显示工具。该模块负责统计帧率，并在指定画面区域内绘制 FPS:xx.x 文本。它只依赖 LCD 绘图接口，不依赖具体摄像头分辨率。

FPS 叠加层适合摄像头预览、动态图像刷新、视频流显示等场景。应用层只需要在每帧成功显示后调用计数函数，再调用绘制函数即可。

1. 模块概览

条目说明
像素格式RGB565
字体内置 5x7 点阵字体，仅包含 FPS 文本所需字符
显示内容FPS:xx.x
统计单位0.1 FPS，例如 306 表示 30.6 FPS
位置模式左上、右上、左下、右下、自定义绝对坐标
开关控制支持运行期启用/关闭显示

2. 模块组成

文件职责
bsp_fps_overlay.h声明配置结构体、位置枚举和 FPS 叠加层 API。
bsp_fps_overlay.c实现 FPS 统计、点阵字体绘制、位置计算、开关控制和 LCD 提交。
bsp_fps_overlay说明文档.html本说明文档。

3. 配置结构体

typedef struct {
    int area_x;
    int area_y;
    int area_w;
    int area_h;
    int margin_x;
    int margin_y;
    int custom_x;
    int custom_y;
    uint8_t scale;
    uint16_t bg_color;
    uint16_t label_color;
    uint16_t value_color;
    bsp_fps_overlay_align_t align;
    bool enabled;
} bsp_fps_overlay_config_t;
字段说明
area_x / area_y绑定画面区域左上角坐标。
area_w / area_h绑定画面区域尺寸。角落定位会基于该区域计算。
margin_x / margin_y使用角落定位时，相对区域边缘的边距。
custom_x / custom_y自定义模式下使用的绝对 LCD 坐标。
scale5x7 字体缩放倍数。传 0 时使用默认值 3。
bg_color叠加层背景色，RGB565。
label_colorFPS: 标签颜色，RGB565。
value_color帧率数值颜色，RGB565。
align显示位置。
enabled是否启用绘制。

3.1 位置枚举

typedef enum {
    BSP_FPS_OVERLAY_ALIGN_TOP_LEFT = 0,
    BSP_FPS_OVERLAY_ALIGN_TOP_RIGHT,
    BSP_FPS_OVERLAY_ALIGN_BOTTOM_LEFT,
    BSP_FPS_OVERLAY_ALIGN_BOTTOM_RIGHT,
    BSP_FPS_OVERLAY_ALIGN_CUSTOM,
} bsp_fps_overlay_align_t;

4. 工作流程

  1. 调用 bsp_fps_overlay_init() 初始化配置和内部 RGB565 缓冲区。
  2. 每次画面成功刷新到 LCD 后调用 bsp_fps_overlay_count_frame()。
  3. 模块每约 1 秒更新一次 FPS 统计值。
  4. 调用 bsp_fps_overlay_draw()，模块根据位置设置绘制 FPS 文本。
  5. 需要隐藏 FPS 时调用 bsp_fps_overlay_set_enabled(false)。

5. 函数说明

bsp_fps_overlay_init(const bsp_fps_overlay_config_t *config)

初始化 FPS 叠加层。传入 NULL 时使用默认配置。初始化会分配内部 RGB565 绘制缓冲区，并重置 FPS 统计窗口。

bsp_fps_overlay_config_t config = {
    .area_x = 0,
    .area_y = 320,
    .area_w = 800,
    .area_h = 640,
    .margin_x = 12,
    .margin_y = 12,
    .scale = 3,
    .bg_color = 0x0000,
    .label_color = 0xFFE0,
    .value_color = 0xFFFF,
    .align = BSP_FPS_OVERLAY_ALIGN_BOTTOM_RIGHT,
    .enabled = true,
};
ESP_ERROR_CHECK(bsp_fps_overlay_init(&config));

bsp_fps_overlay_deinit()

释放内部缓冲区。普通持续显示场景通常不需要频繁调用。

ESP_ERROR_CHECK(bsp_fps_overlay_deinit());

bsp_fps_overlay_set_enabled(bool enabled)

运行期打开或关闭 FPS 绘制。关闭后统计仍可继续进行，但 bsp_fps_overlay_draw() 不会向 LCD 提交像素。

bsp_fps_overlay_set_enabled(false);
bsp_fps_overlay_set_enabled(true);

bsp_fps_overlay_is_enabled()

查询当前是否启用 FPS 显示。

if (bsp_fps_overlay_is_enabled()) {
    ESP_LOGI("app", "FPS overlay is visible");
}

bsp_fps_overlay_set_area(int x, int y, int w, int h)

设置绑定画面区域。该区域用于计算左上、右上、左下、右下等相对位置，适配不同分辨率或不同摆放位置的画面。

ESP_ERROR_CHECK(bsp_fps_overlay_set_area(0, 0, 800, 1280));

bsp_fps_overlay_set_position(bsp_fps_overlay_align_t align, int margin_x, int margin_y)

设置角落位置和边距。

ESP_ERROR_CHECK(bsp_fps_overlay_set_position(BSP_FPS_OVERLAY_ALIGN_TOP_RIGHT, 16, 16));

bsp_fps_overlay_set_custom_position(int x, int y)

设置自定义绝对坐标。调用后位置模式自动切换为 BSP_FPS_OVERLAY_ALIGN_CUSTOM。

ESP_ERROR_CHECK(bsp_fps_overlay_set_custom_position(20, 20));

bsp_fps_overlay_count_frame()

通知模块“已经成功显示一帧”。该函数负责累计帧数并按时间窗口计算 FPS。

bsp_fps_overlay_count_frame();

bsp_fps_overlay_get_fps_x10()

获取当前 FPS，单位为 0.1 FPS。

uint32_t fps_x10 = bsp_fps_overlay_get_fps_x10();
ESP_LOGI("app", "fps=%lu.%lu",
         (unsigned long)(fps_x10 / 10),
         (unsigned long)(fps_x10 % 10));

bsp_fps_overlay_draw()

绘制 FPS 叠加层。内部会调用 LCD 绘图函数并等待传输完成。

ESP_ERROR_CHECK(bsp_fps_overlay_draw());

bsp_fps_overlay_draw_to_rgb565(uint16_t *frame_buffer, int frame_w, int frame_h, int stride_pixels, int screen_x, int screen_y)

将 FPS 叠加层合成到已有的 RGB565 画面缓冲区中，不直接向 LCD 提交刷新。该接口适合摄像头预览等高帧率场景，可以先在帧缓冲内绘制 FPS，再一次性提交整帧，避免额外的 LCD 小区域刷新。

bsp_fps_overlay_count_frame();
ESP_ERROR_CHECK(bsp_fps_overlay_draw_to_rgb565((uint16_t *)frame.buffer,
                                               frame.width,
                                               frame.height,
                                               frame.width,
                                               0,
                                               320));

6. 使用示例

6.1 绑定 800x640 预览区域

bsp_fps_overlay_config_t fps_config = {
    .area_x = 0,
    .area_y = 320,
    .area_w = 800,
    .area_h = 640,
    .margin_x = 12,
    .margin_y = 12,
    .scale = 3,
    .bg_color = 0x0000,
    .label_color = 0xFFE0,
    .value_color = 0xFFFF,
    .align = BSP_FPS_OVERLAY_ALIGN_BOTTOM_RIGHT,
    .enabled = true,
};
ESP_ERROR_CHECK(bsp_fps_overlay_init(&fps_config));

6.2 在显示循环中更新 FPS

// 高帧率预览建议先将 FPS 合成到帧缓冲区，再一次性提交 LCD。
bsp_fps_overlay_count_frame();
ESP_ERROR_CHECK(bsp_fps_overlay_draw_to_rgb565((uint16_t *)frame.buffer,
                                               frame.width,
                                               frame.height,
                                               frame.width,
                                               0,
                                               320));
ESP_ERROR_CHECK(bsp_lcd_draw_bitmap(0, 320, frame.width, 320 + frame.height, frame.buffer));
ESP_ERROR_CHECK(bsp_lcd_wait_flush_done(portMAX_DELAY));

6.3 切换位置

ESP_ERROR_CHECK(bsp_fps_overlay_set_position(BSP_FPS_OVERLAY_ALIGN_TOP_LEFT, 8, 8));
ESP_ERROR_CHECK(bsp_fps_overlay_set_position(BSP_FPS_OVERLAY_ALIGN_BOTTOM_RIGHT, 12, 12));
ESP_ERROR_CHECK(bsp_fps_overlay_set_custom_position(100, 100));

6.4 开启和关闭显示

bsp_fps_overlay_set_enabled(false); // 隐藏
bsp_fps_overlay_set_enabled(true);  // 显示

7. 注意事项

  • 该模块默认绘制 RGB565 像素，要求 LCD 绘图接口也按 RGB565 接收数据。
  • bsp_fps_overlay_draw() 会等待 LCD 区域刷新完成，因此它会占用一小段显示时间。
  • 对于实时视频预览，优先使用 bsp_fps_overlay_draw_to_rgb565()，可以将 FPS 和主画面合并为一次 LCD 刷新。
  • 显示关闭后，bsp_fps_overlay_count_frame() 仍会继续统计帧率。
  • 绑定区域可以是整屏，也可以是摄像头预览区域。角落定位全部基于绑定区域计算。
  • 自定义位置是 LCD 绝对坐标，不受绑定区域边距影响。
  • 如果修改字体缩放倍数，应重新调用 bsp_fps_overlay_init() 或扩展接口以重建缓冲区。
