BSP LCD JD9365 10.1 + GT9271 触摸说明文档

本文档说明 JD9365 10.1 寸 MIPI-DSI LCD 与 GT9271 十点触摸的 BSP 封装接口。该模块基于 waveshare/esp_lcd_jd9365_10_1 组件驱动屏幕，并通过 I2C 读取 GT9271 触摸数据。

本 BSP 的目标是给应用层提供稳定、简洁的屏幕和触摸接口。应用层无需直接操作 MIPI-DSI、DBI IO、DPI panel 或 GT9271 原始寄存器。

4. 初始化流程

  1. 调用 bsp_lcd_init()。
  2. 配置并打开背光 GPIO。
  3. 打开 MIPI DSI PHY LDO。
  4. 创建 MIPI DSI bus。
  5. 创建 MIPI DBI command IO。
  6. 创建 JD9365 panel。
  7. 执行 panel reset、init、display on。
  8. 注册 DPI 传输完成回调。
  9. 调用 bsp_touch_init() 初始化 GT9271。
  10. 应用循环中调用 bsp_touch_read_points() 读取触摸点。

5. LCD 函数说明

bsp_lcd_init()

初始化 LCD 显示链路。该函数是幂等的，重复调用会直接返回 ESP_OK。

ESP_ERROR_CHECK(bsp_lcd_init());

bsp_lcd_deinit()

释放 LCD 和触摸相关资源。适合测试程序或低功耗场景使用。

ESP_ERROR_CHECK(bsp_lcd_deinit());

bsp_lcd_get_panel()

返回底层 esp_lcd_panel_handle_t，用于直接调用 esp_lcd 或 MIPI DPI 扩展 API。

esp_lcd_panel_handle_t panel = bsp_lcd_get_panel();

bsp_lcd_set_backlight(bool on)

控制背光 GPIO。关闭背光不会停止 LCD 扫描，只是屏幕不可见。

ESP_ERROR_CHECK(bsp_lcd_set_backlight(true));
ESP_ERROR_CHECK(bsp_lcd_set_backlight(false));

bsp_lcd_display_on(bool on)

发送 LCD Display ON/OFF 命令。它和背光控制是两件不同的事。

ESP_ERROR_CHECK(bsp_lcd_display_on(true));
ESP_ERROR_CHECK(bsp_lcd_display_on(false));

bsp_lcd_invert_color(bool invert)

开启或关闭颜色反相。

ESP_ERROR_CHECK(bsp_lcd_invert_color(true));
ESP_ERROR_CHECK(bsp_lcd_invert_color(false));

bsp_lcd_mirror(bool mirror_x, bool mirror_y)

设置 X/Y 镜像。JD9365 当前封装不支持 swap_xy，因此不能仅靠该函数完成 90 度旋转。

ESP_ERROR_CHECK(bsp_lcd_mirror(true, false));

bsp_lcd_draw_bitmap(...)

向指定区域提交像素数据。坐标区间是左上角包含、右下角不包含。

ESP_ERROR_CHECK(bsp_lcd_draw_bitmap(0, 0, 100, 80, buffer));
如果复用同一块 DMA 缓冲区，提交后应调用 bsp_lcd_wait_flush_done()，等待传输完成后再改写缓冲区。

bsp_lcd_wait_flush_done(TickType_t timeout_ticks)

等待 DPI 颜色数据传输完成。

ESP_ERROR_CHECK(bsp_lcd_wait_flush_done(portMAX_DELAY));

6. 触摸函数说明

bsp_touch_init()

初始化 GT9271 触摸芯片。函数会先尝试地址 0x14，失败后尝试 0x5D，并读取 Product ID 确认设备存在。

esp_err_t ret = bsp_touch_init();
if (ret == ESP_OK) {
    ESP_LOGI(TAG, "Touch ready");
}

bsp_touch_deinit()

释放触摸设备句柄。该函数不会主动删除 I2C1 bus，避免影响 LCD 组件内部使用的 I2C 资源。

ESP_ERROR_CHECK(bsp_touch_deinit());

bsp_touch_read_points(bsp_touch_data_t *data)

读取当前触摸点。无新数据时返回 ESP_OK 且 data.count == 0。有新数据时返回最多 10 个触摸点，并清除 GT9271 状态寄存器。

bsp_touch_data_t touch = {0};
ESP_ERROR_CHECK(bsp_touch_read_points(&touch));

ESP_LOGI(TAG, "touch count: %u", touch.count);
for (uint8_t i = 0; i < touch.count; i++) {
    ESP_LOGI(TAG, "id=%u x=%u y=%u size=%u",
             touch.points[i].id,
             touch.points[i].x,
             touch.points[i].y,
             touch.points[i].size);
}

7. 使用示例

7.1 初始化 LCD 和触摸

#include "bsp_lcd_jd9365_10_1.h"

void app_main(void)
{
    ESP_ERROR_CHECK(bsp_lcd_init());

    esp_err_t ret = bsp_touch_init();
    if (ret != ESP_OK) {
        ESP_LOGW("app", "touch init failed: %s", esp_err_to_name(ret));
    }
}

7.2 绘制一个纯色矩形

#define RECT_W 100
#define RECT_H 80

uint16_t *buf = heap_caps_malloc(RECT_W * RECT_H * sizeof(uint16_t),
                                 MALLOC_CAP_DMA | MALLOC_CAP_8BIT);

for (int i = 0; i < RECT_W * RECT_H; i++) {
    buf[i] = 0xF800; // RGB565 red
}

ESP_ERROR_CHECK(bsp_lcd_draw_bitmap(0, 0, RECT_W, RECT_H, buf));
ESP_ERROR_CHECK(bsp_lcd_wait_flush_done(portMAX_DELAY));

7.3 周期性检测触摸

while (1) {
    bsp_touch_data_t touch = {0};
    if (bsp_touch_read_points(&touch) == ESP_OK) {
        ESP_LOGI("touch", "count=%u", touch.count);
        for (uint8_t i = 0; i < touch.count; i++) {
            ESP_LOGI("touch", "[%u] id=%u x=%u y=%u size=%u",
                     i,
                     touch.points[i].id,
                     touch.points[i].x,
                     touch.points[i].y,
                     touch.points[i].size);
        }
    }
    vTaskDelay(pdMS_TO_TICKS(20));
}

8. 注意事项

  • LCD 默认像素格式是 RGB565，绘图缓冲区每个像素必须提供 2 字节。
  • 大面积绘图建议使用 MALLOC_CAP_DMA 分配缓冲区。
  • 复用绘图缓冲区前，应等待 bsp_lcd_wait_flush_done() 返回成功。
  • 触摸检测频率由应用层控制。如果放在较慢的 UI 刷新循环中，触摸响应也会变慢。
  • GT9271 的 I2C 地址可能是 0x14 或 0x5D，BSP 会自动尝试两个地址。
  • I2C1/GPIO7/GPIO8 同时被触摸和屏幕板载器件使用，修改这些引脚时需要同步检查 LCD 驱动内部逻辑。
