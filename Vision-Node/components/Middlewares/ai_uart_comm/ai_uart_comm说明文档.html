AI UART Comm 主从通信中间件说明文档

本文档说明 ai_uart_comm 中间件的职责、数据格式、主从调用方式和串口协议。该模块用于两块 ESP32-P4 之间的有线 UART 通信：从机负责实时执行 FACE/EXPR/HAND/GEST 识别，主机负责查询当前状态、切换识别模式并读取结构化识别结果。

应用层只需要操作结构体和函数，不需要在 main_master.c 或 main_slave.c 中手写串口命令解析、字符串拼接或协议状态机。

3. 硬件连接

当前工程在主机和从机中均使用 UART1，默认配置为 TX GPIO4、RX GPIO5。两块板连接时需要交叉 TX/RX，并共地。

主机 GPIO4(TX) -> 从机 GPIO5(RX)
主机 GPIO5(RX) -> 从机 GPIO4(TX)
主机 GND       -> 从机 GND
不要把两块板的 TX 直接接 TX、RX 直接接 RX。UART 是点对点异步串口，必须 TX 接对方 RX。

4. 数据结构

ai_uart_config_t

初始化 UART 使用的配置，由主机和从机各自传入。模块不固定硬件引脚，方便后续换线。

typedef struct {
    uart_port_t port;
    gpio_num_t tx_gpio;
    gpio_num_t rx_gpio;
    int baud_rate;
} ai_uart_config_t;

ai_uart_snapshot_t

从机返回给主机的一次识别快照。一个快照包含当前模式、更新序号和多个识别目标。

typedef struct {
    uint32_t sequence;
    ai_uart_mode_t mode;
    size_t object_count;
    ai_uart_object_t objects[AI_UART_MAX_OBJECTS];
} ai_uart_snapshot_t;

ai_uart_object_t

一个识别目标的数据。FACE/EXPR 表示一个人脸目标，HAND/GEST 表示一个手部目标。

typedef struct {
    uint16_t x10;
    uint16_t y10;
    int16_t action;
    uint16_t detect_confidence;
    uint16_t action_confidence;
} ai_uart_object_t;
字段单位/范围说明
x100~1000目标中心点 X 百分比 x10。例如 500 表示画面宽度 50.0%。
y100~1000目标中心点 Y 百分比 x10。例如 250 表示画面高度 25.0%。
action-1 或编码值EXPR 模式为表情编码，GEST 模式为手势编码；FACE/HAND 纯检测模式为 -1。
detect_confidence0~1000检测置信度 x1000。FACE/HAND 纯检测模式当前按需求不发送置信度，置 0。
action_confidence0~1000动作/手势置信度 x1000。无动作识别时置 0。

5. 串口协议

模块内部使用文本行协议，便于串口助手调试。应用层不需要直接拼接这些字符串。

5.1 主机命令

命令说明
GET\n查询从机当前快照。
NEXT\n从机切换到下一个模式，顺序为 FACE -> EXPR -> HAND -> GEST -> FACE。
SET,0\n切换到 FACE 模式。
SET,1\n切换到 EXPR 模式。
SET,2\n切换到 HAND 模式。
SET,3\n切换到 GEST 模式。

5.2 从机响应

从机先发送快照头，再按目标数量发送目标行。

R,<sequence>,<mode>,<object_count>
O,<x10>,<y10>,<action>,<detect_confidence>,<action_confidence>
O,<x10>,<y10>,<action>,<detect_confidence>,<action_confidence>

例如 GEST 模式检测到两个手部目标：

R,128,3,2
O,321,456,6,912,887
O,701,430,5,853,801

6. 初始化 API

ai_uart_init(const ai_uart_config_t *config)

初始化 UART 驱动、波特率、数据位、停止位、流控和 TX/RX 引脚。主机和从机都必须先调用一次。

const ai_uart_config_t uart_config = {
    .port = UART_NUM_1,
    .tx_gpio = GPIO_NUM_4,
    .rx_gpio = GPIO_NUM_5,
    .baud_rate = 115200,
};
ESP_ERROR_CHECK(ai_uart_init(&uart_config));

7. 主机 API

ai_uart_master_send_get()

向从机发送查询命令。调用后需要周期性调用 ai_uart_master_poll_snapshot() 接收响应。

ai_uart_master_send_next()

要求从机切换到下一个识别模式。

ai_uart_master_send_set_mode(ai_uart_mode_t mode)

要求从机切换到指定模式。

ESP_ERROR_CHECK(ai_uart_master_send_set_mode(AI_UART_MODE_GEST));

ai_uart_master_poll_snapshot(ai_uart_snapshot_t *snapshot)

非阻塞接收从机数据。当收满一个完整快照时返回 true，并把数据写入 snapshot。

ai_uart_snapshot_t snapshot;
while (ai_uart_master_poll_snapshot(&snapshot)) {
    ESP_LOGI(TAG, "seq=%lu mode=%s count=%u",
             (unsigned long)snapshot.sequence,
             ai_uart_mode_name(snapshot.mode),
             (unsigned)snapshot.object_count);
}

8. 从机 API

ai_uart_slave_poll_command(ai_uart_command_t *command)

非阻塞读取主机命令。当收到完整命令时返回 true。从机应用层根据命令类型决定查询、切换或设置模式。

ai_uart_slave_send_snapshot(const ai_uart_snapshot_t *snapshot)

把从机当前快照发送给主机。一次发送包含一行 R 头和若干行 O 目标数据。

9. 使用示例

9.1 主机周期查询

while (1) {
    ESP_ERROR_CHECK(ai_uart_master_send_get());

    ai_uart_snapshot_t snapshot;
    while (ai_uart_master_poll_snapshot(&snapshot)) {
        for (size_t i = 0; i < snapshot.object_count; i++) {
            const ai_uart_object_t *obj = &snapshot.objects[i];
            ESP_LOGI(TAG, "x10=%u y10=%u action=%d",
                     obj->x10, obj->y10, obj->action);
        }
    }

    vTaskDelay(pdMS_TO_TICKS(100));
}

9.2 从机响应查询

ai_uart_command_t command;
while (ai_uart_slave_poll_command(&command)) {
    if (command.type == AI_UART_CMD_GET) {
        ESP_ERROR_CHECK(ai_uart_slave_send_snapshot(&snapshot));
    } else if (command.type == AI_UART_CMD_NEXT) {
        mode = (ai_uart_mode_t)((mode + 1) % AI_UART_MODE_COUNT);
    } else if (command.type == AI_UART_CMD_SET_MODE) {
        mode = command.mode;
    }
}

11. 注意事项

  • 本模块传输的是识别结果，不传输图像，因此 115200 波特率通常已经足够。需要更高查询频率时，可把主从两端波特率同时提高到 921600。
  • AI_UART_MAX_OBJECTS 当前为 4，与检测结果数组容量保持一致。若后续要传更多目标，需要同时调整检测结果容量和通信数组容量。
  • x10、y10 表示目标框中心点，不表示框宽高。若主机后续需要画框，需要扩展协议增加宽高字段。
  • FACE/HAND 纯检测模式按当前需求只发送坐标，检测置信度字段置 0。EXPR/GEST 模式才发送检测置信度和动作置信度。
  • 主机接收函数是非阻塞的，应在主循环中高频调用，避免 UART 接收缓冲区堆积。
  • 主机和从机必须共地，否则 UART 电平没有共同参考，通信会不稳定或完全失败。
